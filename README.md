# Omarchy

A fork of [Omarchy](https://github.com/basecamp/omarchy) by DHH, with AI agents and several of its default applications removed.

## What's Changed

1. AI agents and gaming-related components have been removed.
2. Docker, Kdenlive, LibreOffice, OBS Studio, and Obsidian have been removed.
3. Google-related desktop entries have been removed. Firefox is preinstalled but is not configured as the default browser.
